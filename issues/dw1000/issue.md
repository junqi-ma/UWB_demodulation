# 调研 DW1000 连续发射模式与 EVM 测试可行性

## 动机

当前接收到的 DW1000 波形 EVM 较高，尤其存在明显的相位噪声，导致波形重建和 SIC 消除效果不稳定。希望研究发射功率、天线及射频配置对 EVM 的影响。

## 遇到的问题

- 需要区分固定频偏、随机相位噪声和发射启动瞬态。
- 尚不确定 DW1000 是否支持可用于测试的 Continuous Pulse 和 Continuous Wave 模式。
- 不清楚这些模式的寄存器、SDK 接口、限制及推荐配置。

## 调研需求

请阅读 DW1000 datasheet、user manual、寄存器数据库、SDK/API 和示例代码，回答：

1. 是否支持持续发送 UWB pulse 的 Continuous Pulse 测试模式？
2. 是否支持持续发送单载波的 Continuous Wave 测试模式？
3. 两种模式分别如何配置？请给出寄存器或 API、关键参数和退出/复位方法。
4. 发射功率可以如何调节？哪些参数适合用于 EVM 对比实验？
5. 是否存在持续发射时长、温度、法规或硬件安全方面的限制？

## 期望输出

- 明确结论：可行、部分可行或不可行。
- 给出对应资料章节、寄存器或代码位置作为依据。
- 提供最小配置流程。
- 给出“发射功率 × 天线 × 测试模式”的简要实验方案，用 X410 采集 IQ 并比较 EVM、频偏和相位波动。
