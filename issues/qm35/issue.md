# 调研 QM35825 非睡眠发射与起始相移测试可行性

## 动机

QM35825（项目中简称 QM35）信号在开始阶段存在快速相移，导致重建波形无法完全匹配，QM35 消除残留进一步影响 DW1000 解调和 SIC。

## 遇到的问题

- 快速相移可能来自 PA 开启瞬态或 PLL 重新初始化/锁定。
- 尚不清楚每次发射前芯片是否进入睡眠并重新启动射频链路。
- 不确定能否配置为非睡眠或持续工作模式，以保持 PA、PLL 或本振状态稳定。

## 调研需求

请阅读 QM35825 datasheet、寄存器数据库、SDK/API 和示例代码，回答：

1. 芯片有哪些睡眠、待机和持续工作模式？
2. 能否避免每次 UWB 发射前重新初始化 PLL 或射频链路？
3. 能否保持 PLL、本振或 PA 持续工作？对应的寄存器/API 和配置顺序是什么？
4. 是否提供连续发射、测试帧或其他适合观察起始相位的测试模式？
5. 上述配置是否存在功耗、温度、发射时长或硬件安全限制？

## 期望输出

- 明确结论：可行、部分可行或不可行。
- 给出对应资料章节、寄存器或代码位置作为依据。
- 提供最小配置流程。
- 设计“默认睡眠模式 vs 非睡眠模式”的对比实验，用 X410 采集 IQ，比较信号起始阶段的相位轨迹、稳定时间及消除残差。
