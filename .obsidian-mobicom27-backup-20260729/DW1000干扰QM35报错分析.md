# QM35825 雷达模式受 DW1000 同频干扰分析与解决

## 现象

运行 Cherry radar 例程时，若同时打开同频段 DW1000 持续报错：

```
ERROR qorvo.uwb.uci: handle_full_message: error -11 occurred while processing message with header 0x0F00
```

## 根因分析

### 错误码含义

- **`-11`** = `QERR_EINVAL`（`qerr.h:60`）— 无效参数
- **`0x0F00`** = UCI DATA 包，DPF = `0xF` = `UCI_MESSAGE_DPF_RADAR`（雷达数据）

### 报错链路

```
DW1000 同频干扰
    ↓
QM35825 雷达采样异常，固件内部数据搬运/处理逻辑出错
    ↓
UWBS 发送格式错乱的 Radar Report Notification
    ↓
uci_radar_data_handler() 解析失败 → goto err → 返回 QERR_EINVAL (-11)
    ↓
handle_full_message() 打印 error -11
```

### 关键发现：固件已有 inband signal 检测机制

`uci_spec_fira.h:652` 定义了：

```c
UCI_SESSION_REASON_SESSION_STOPPED_DUE_TO_INBAND_SIGNAL = 0x05
```

说明 **UWBS 固件本身具备"检测到同频信号"的能力**。干扰场景下固件有三种可能的反应路径：

| 路径 | 表现 | 是否正常 |
|------|------|----------|
| A. 固件通过 reason `0x05` 主动 stop session | 应用层收到 `SESSION_STATUS` 通知 | 正常设计 |
| B. 固件标记 `CHERRY_RADAR_REPORT_STATUS_ERROR` 后上报 | handler 走 `goto callback` 交付报告 | 正常降级 |
| **C. 固件内部异常，发送格式错乱的 payload** | parser → `goto err` → **返回 -11** | **Bug** |

当前走的是路径 C — 干扰严重到固件雷达处理逻辑本身异常，且主机 parser 缺乏容错。

## 解决方案

### 目标

干扰应体现为 **CIR 数据出现杂波**，而非软件栈报错崩溃。

### 修改 1：放宽 Radar Report status 检查（最关键）

`cherry_radar_client.c:115-116`：

```c
// 原代码：非 SUCCESS 即丢弃
if (report->data->status != CHERRY_RADAR_REPORT_STATUS_SUCCESS)
    goto err;

// 改为：非 SUCCESS 也尝试解析交付
if (report->data->status != CHERRY_RADAR_REPORT_STATUS_SUCCESS) {
    QLOGW("%s: radar status=0x%02X, attempting partial delivery",
          __func__, report->data->status);
}
```

### 修改 2：容忍尾部多余字节

`cherry_radar_client.c:142-144`：

```c
// 原代码：有多余数据即丢弃
if (uci_message_remaining(&parser))
    goto err;

// 改为：仅警告
if (uci_message_remaining(&parser))
    QLOGW("%s: %zu trailing bytes, possible interference",
          __func__, uci_message_remaining(&parser));
```

### 修改 3：降级 UCI core 错误日志级别

`uci.c:382-384`：将 radar NTF handler 返回的错误从 `QLOGE` 降为 `QLOGW`，避免干扰场景下日志刷屏。

### 修改 4：应用层处理 inband signal 通知

`radar_app.c` 的 `radar_cb` 中增加对 `SESSION_STATUS` + reason `0x05` 的处理：

```c
case CHERRY_RADAR_EVENT_TYPE_SESSION_STATUS:
    if (event->data.status->reason_code ==
        CHERRY_RADAR_STATE_CHANGE_REASON_INBAND_SIGNAL) {
        QLOGW("Radar session stopped due to inband signal interference");
    }
    break;
```

## 补充：规避手段

| 方法 | 说明 |
|------|------|
| 频段错开 | QM35825 用 Channel 9，DW1000 改用 Channel 5 |
| 空间隔离 | 增大两天线物理距离 |
| 时分复用 | 错开两者发射时段 |
