# DW1000单音相位噪声与 Cancellation 影响分析

> [!summary] 核心结论
> DW1000 单音经过 X410 接收后，在 10 Hz～2 MHz 内测得 **9.77° RMS** 的积分相位噪声；完整 0.49981 s 记录在去除固定载波和最佳线性频偏后仍有 **24.22° RMS**、**133.82°峰峰值**的相位变化。固定复系数或固定 CIR 无法跟踪这种时变相位，是 cancellation 消除不深的重要原因。100 kHz 隆起对完整积分方差只贡献约 **2.39%**，但在 10 kHz 以上的快速相位噪声中贡献约 **14.55%**。

## 1. 实验配置

| 项目 | 参数 |
|---|---:|
| 发射信号 | DW1000 continuous single tone |
| IQ 文件 | `F:\UWB基带数据\dw1000_single_tone_1.dat` |
| 接收设备 | USRP X410 |
| X410 中心频率 | 6489.6 MHz |
| 采样率 | 737.28 MS/s |
| 原始复采样点数 | 368,500,000 |
| 记录时长 | 0.499810 s |
| IQ 格式 | 单通道、交织 `int16`，顺序为 I/Q |
| 相位分析抽取倍数 | 64 |
| 抽取后采样率 | 11.52 MS/s |
| Welch 频率分辨率 | 10.986 Hz |
| 默认积分频带 | 10 Hz～2 MHz |

处理流程：

1. 从原始 IQ 数据中估计单音载波频率。
2. 复数下变频至零频。
3. 使用 Hann 加权的分块相干平均进行 64 倍带限抽取。
4. 对相位解缠，并去除固定相位和最佳线性频偏。
5. 对完整抽取后相位序列做时域统计。
6. 用 Welch 方法估计相位 PSD，并按
   \[
   L(f)=10\log_{10}\left(\frac{S_\phi(f)}{2}\right)
   \]
   换算为单边带相位噪声，单位为 dBc/Hz。

> [!note] 测量边界
> 本结果是 **DW1000 发射机 + X410 接收本振 + 两端参考时钟 + 采样时钟 + 接收噪声** 的合成残余相位噪声，不能直接视为 DW1000 单机绝对相位噪声。

## 3. 完整记录的相位变化

![](./DW1000单音相位噪声附件/dw1000_single_tone_1_phase_noise.png)

图中左下角给出了完整 0.5 s 的残余相位。计算使用全部约 575.8 万个抽取后相位样本，绘图为了控制大小进一步每 29 点显示一点；绘图抽样不影响统计结果。

### 3.1 全记录统计

以下结果均已去除固定载波和最佳线性频偏：

| 指标 | 相位角度 |
|---|---:|
| 均值 | 约 0° |
| 中位数 | −4.55° |
| 标准差 | 24.22° |
| RMS | 24.22° |
| 最小值 | −51.72° |
| 最大值 | +82.10° |
| 峰峰值 | 133.82° |
| 1%～99%区间 | −37.25°～+59.43° |
| 1%～99%跨度 | 96.69° |
| 首尾相位变化 | −31.25° |

完整记录的相位呈明显的缓慢弯曲，而不是围绕固定均值的纯白噪声。这说明记录中存在显著的低频频率漂移或相对时钟漂移。

相位是频率误差的积分：

$$
\Delta f=\frac{\Delta\phi}{2\pi T}
$$

例如，0.5 s 内积累 30° 相位变化只对应约 0.167 Hz 的平均频率变化。相对于 6.48 GHz，这个频率比例非常小，但对需要高精度相位匹配的 cancellation 已经足以造成明显残差。

### 3.2 相位噪声积分结果

| 积分频带 | RMS相位误差 |
|---|---:|
| 完整时域记录（包含极低频漂移） | 24.22° |
| 10 Hz～2 MHz | 9.77° |
| 1 kHz～2 MHz | 4.07° |
| 10 kHz～2 MHz | 3.96° |
| 50 kHz～2 MHz | 3.86° |

完整记录 RMS 显著大于 10 Hz～2 MHz 积分结果，表明 **10 Hz 以下的慢速漂移是全记录相位变化的主要来源**。

### 3.3 典型频偏点

| Offset | 相位噪声 |
|---:|---:|
| 100 Hz | −60.18 dBc/Hz |
| 1 kHz | −76.19 dBc/Hz |
| 10 kHz | −82.64 dBc/Hz |
| 100 kHz | −80.25 dBc/Hz |
| 1 MHz | −93.85 dBc/Hz |

频谱中约 100 kHz 处存在宽隆起，约 1.4 MHz 处还存在窄带杂散。

## 4. 100 kHz 隆起的贡献

![](./DW1000单音相位噪声附件/dw1000_100khz_bump_contribution.png)

定量计算中将隆起定义为 50～160 kHz，并用 30～50 kHz 与 160～250 kHz 两侧 PSD 在对数坐标下拟合局部背景噪声。将实测 PSD 超出该背景的正差值视为隆起的额外贡献。

| 指标 | 结果 |
|---|---:|
| 50～160 kHz频段总噪声 | 1.73° RMS |
| 局部背景噪声 | 0.86° RMS |
| 隆起额外贡献 | 等效 1.51° RMS |
| 隆起占50～160 kHz局部方差 | 76.08% |

隆起对不同积分范围的影响如下：

| 积分范围 | 原始RMS | 去掉隆起后 | 隆起方差占比 |
|---|---:|---:|---:|
| 10 Hz～2 MHz | 9.77° | 9.66° | 2.39% |
| 1 kHz～2 MHz | 4.07° | 3.78° | 13.77% |
| 10 kHz～2 MHz | 3.96° | 3.66° | 14.55% |
| 50 kHz～2 MHz | 3.86° | 3.56° | 15.27% |

因此，100 kHz 隆起虽然在局部频谱中非常突出，却不是完整 10 Hz～2 MHz 积分相位噪声的主要来源。它对快速相位变化仍有约 14%～15% 的方差贡献，如果 cancellation 的相位跟踪带宽低于该频段，这部分误差将难以被实时跟踪。

## 5. 对 Cancellation 的影响

只考虑相位失配、假设幅度和时延完全正确，抵消后的残余幅度比例为：

$$
\frac{|r|}{|s|}
=
\left|1-e^{j\Delta\phi}\right|
=
2\sin\left(\frac{|\Delta\phi|}{2}\right)
$$

| 相位误差 | 残余幅度 | 理论抑制度 |
|---:|---:|---:|
| 1° | 1.7% | 35.2 dB |
| 5° | 8.7% | 21.2 dB |
| 10° | 17.4% | 15.2 dB |
| 20° | 34.7% | 9.2 dB |
| 30° | 51.8% | 5.7 dB |

本次 10 Hz～2 MHz 积分相位误差为 9.77°，对应仅由随机相位误差决定的 cancellation 上限约 15 dB。若使用完整记录的 24.22° RMS，固定相位参考的平均抑制度上限大约只有 7～8 dB。

这解释了为什么即使已经正确重建 DW1000 波形、估计幅度和 CIR，使用固定复系数仍然难以获得深度消除：真实接收信号的相位并不固定。

## 6. DW1000与X410的可能贡献

X410 官方给出的 TX 相位噪声典型值是在 1 GHz 载波下测得：

| Offset | X410官方TX典型值 | 本次DW1000→X410整链路 |
|---:|---:|---:|
| 1 kHz | −91 dBc/Hz | −76.19 dBc/Hz |
| 10 kHz | −101 dBc/Hz | −82.64 dBc/Hz |
| 100 kHz | −103 dBc/Hz | −80.25 dBc/Hz |

官方规格链接：[Ettus USRP X410 Specifications](https://www.ni.com/docs/en-US/bundle/ettus-usrp-x410-specs/page/specs.html)

两者并非严格可直接比较：官方值是 X410 在 1 GHz 下的 TX 指标，而本实验是 6.48 GHz 附近的 DW1000 TX 与 X410 RX 合成测量。不过，本次整链路在 1 kHz～100 kHz 明显更差，结合 100 kHz 隆起，说明 DW1000 PLL、参考晶振或供电噪声很可能是重要贡献者。

DW1000是面向脉冲UWB通信和测距的芯片，并非低相噪连续波信号源。CW测试模式下较差的长期相位稳定性不一定意味着正常UWB功能异常，但它会直接限制基于确定性重建波形的相干干扰消除。

## 7. 后续建议

### 7.1 分离噪声来源

在保持 X410 接收中心频率、采样率、增益和分析脚本不变的情况下，依次采集：

1. DW1000 单音；
2. X410 发送单音；
3. 高质量射频信号源单音；
4. 使用共同 10 MHz 参考后的单音。

分别比较：

- 完整 0.5 s 相位 RMS 与峰峰值；
- 10 Hz～2 MHz 积分 RMS；
- 100 kHz 隆起是否存在；
- 1.4 MHz 杂散是否存在。

如果换成低相噪信号源后曲线明显下降，则可确认 DW1000 是主要贡献者；如果隆起仍然存在，则应进一步检查 X410 接收链、参考时钟和采样时钟。

### 7.2 改进 cancellation

固定复系数模型

$$
\hat{s}(t)=a e^{j\phi_0}s_{\mathrm{reconstructed}}(t)
$$

应升级为时变相位模型：

$$
\hat{s}(t)=a(t)e^{j\hat{\phi}(t)}
s_{\mathrm{reconstructed}}(t)
$$

建议依次尝试：

- 对重建波形分块估计复系数；
- 对块间相位做解缠和平滑插值；
- 使用 PLL 或 Kalman filter 跟踪公共相位误差；
- 单独建模约 100 kHz 隆起和 1.4 MHz 杂散；
- 在多径模型中让主要路径共享公共相位轨迹，同时保留各路径固定或慢变的复增益。

窗口越短，相位跟踪带宽越高，但系数估计噪声也越大，需要通过 cancellation 深度实测选择折中点。
