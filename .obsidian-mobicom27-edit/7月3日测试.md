# 7月3日 UWB 雷达与通信干扰测试

## 🎯 实验目的 / 对应假设

<!-- 这个实验在验证项目页里的哪一条假设/哪个Go-No-Go检查点 -->

- UWB 通信设备
- 人体呼吸目标

**软件/工具：**

- 待补充

| 参数 | 值 |

| 通信信道 | Channel 9 / Channel 10 |
| 雷达长度 | 默认 / 256 / 128 |
| 通信长度 | 默认 / 64 |

## 📋 实验步骤

1. 雷达和通信设置为channel9测试干扰，人体呼吸 breath1-2
2. 雷达设置为channel9，通信设置为channel10测试干扰，人体呼吸 breath3
3. 雷达设置为channel9，通信设置为channel10测试干扰，雷达长度256，通信长度64 人体呼吸 breath4-5
4. 雷达设置为channel9，通信设置为channel10测试干扰，雷达长度128，通信长度64 人体呼吸 breath6
