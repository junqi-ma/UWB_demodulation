# 7月28日实验计划：DW1000 相位噪声与 QM35 起始相移

> [!goal] 实验目标
> 确认 DW1000 相位噪声来源，以及 QM35 起始相移是否与睡眠唤醒有关。

```mermaid
flowchart LR
    A["设备与采集检查"] --> B["DW1000 CW"]
    B --> C["DW1000 连续帧"]
    C --> D["QM35 默认模式"]
    D --> E["QM35 非睡眠模式"]
    E --> F["对比结果并决定下一步"]
```

## 0. 测试前检查（20 分钟）

- [ ] 使用屏蔽环境或射频电缆，并配置合适衰减。
- [ ] DW1000、QM35 均从低功率开始。
- [ ] 确认 X410 接收未饱和。
- [ ] 固定采样率、接收增益、线缆和距离。
- [ ] 建立今日结果目录，记录每次测试配置。

---

## 1. DW1000 CW 测试（40 分钟）

目的：测量不含调制影响的 CFO 和相位噪声。

- [ ] 运行官方 `ex_04a_cont_wave`。
- [ ] 使用 X410 采集至少 10 ms IQ。
- [ ] 测试低、中、高三档发射功率。
- [ ] 条件允许时，对比射频电缆和天线。

记录：

- 接收功率；
- CFO；
- 去除 CFO 后的相位标准差；
- 相位噪声是否随功率、天线或温度变化。

---

## 2. DW1000 连续帧测试（40 分钟）

目的：测量真实 UWB 调制波形的 EVM。

- [ ] 运行官方 `ex_04b_cont_frame`。
- [ ] 固定发送同一帧，采集至少 100 个 packet。
- [ ] 使用与 CW 测试相同的功率配置。
- [ ] 比较不同功率下的 EVM 和 packet 间相位一致性。

判断：

- 若 CW 相位稳定而连续帧 EVM 高，重点检查 PA 启动和帧内瞬态。
- 若 CW 本身相位噪声高，重点检查本振、PLL、电源和温度。

---

## 3. QM35 默认模式测试（30 分钟）

目的：记录当前起始快速相移的基线。

- [ ] 保持默认低功耗设置。
- [ ] 使用 Periodic TX 发送固定帧。
- [ ] X410 采集至少 100 个 packet。
- [ ] 读取并保存 Power Stats。

记录：

- packet 起始相移；
- 相位稳定时间；
- packet 间相位一致性；
- `wakeup_cnt`、S1/S3 时间；
- 当前消除残差。

---

## 4. QM35 非睡眠模式测试（40 分钟）

配置：

```text
LowPowerMode = 0
PmMinInactivityS4 = 4294967295
```

- [ ] 保持其他参数与默认模式完全一致。
- [ ] 再次发送相同的 Periodic TX。
- [ ] 采集相同数量的 packet。
- [ ] 再次读取 Power Stats。
- [ ] 对比起始相位和消除残差。

判断：

- **快速相移明显减小：**睡眠唤醒或 PLL 重新锁定是主要原因。
- **快速相移没有变化：**更可能是 PA 每帧开启或固件内部 RF 时序。
- **唤醒次数没有下降：**非睡眠配置可能未生效，需要检查固件能力和配置返回值。
